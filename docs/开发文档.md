# 开发文档

本文描述当前实现。用户使用见 [README](../README.md)，贡献流程见 [CONTRIBUTING](../CONTRIBUTING.md)。

## 环境与命令

仅维护 Windows x64。使用 Node.js 22.12+（推荐 24 LTS）、npm、Rust stable MSVC、Windows SDK、C++ Build Tools 和 WebView2。

```powershell
npm ci
npm run desktop:dev
```

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 浏览器预览，固定端口 1420 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm test` | Vitest 单元测试 |
| `npm run build` | 类型检查并生成前端生产资源 |
| `npm run desktop:dev` | Tauri 开发窗口 |
| `npm run desktop:check` | Cargo 编译检查，使用锁文件 |
| `npm run desktop:test` | Rust 默认测试，使用锁文件 |
| `npm run desktop:fmt` | 格式化 Rust |
| `npm run desktop:fmt:check` | 只检查 Rust 格式 |
| `npm run desktop:build` | 构建 Windows release 和 NSIS 安装包 |

### 标准与便携工具链

`scripts/desktop.ps1` 加载 `scripts/env.ps1`，不修改系统级 PATH 或用户环境变量。

- 通常使用 PATH 中的 Rust，以及已安装的 Visual Studio / Windows SDK。
- 同时存在 `.tools/cargo/bin/cargo.exe` 和 `.tools/rustup/` 时自动使用项目内 Rust。
- 存在 `.tools/msvc/` 时自动读取其中的 MSVC / Windows SDK；这些二进制不属于仓库。
- 桌面命令支持 `-SystemToolchain`，跳过项目内工具链，例如 `npm run desktop:check -- -SystemToolchain`。请在新终端调用，避免继承已经覆盖的工具链变量。
- 桌面脚本将 Cargo 产物、临时文件和打包缓存放到项目目录，附加静态 CRT 编译选项。
- 便携 Rust 模式兼容项目内 APPDATA / LOCALAPPDATA 缓存；标准模式保留系统的应用数据环境。
- 脚本不会安装 Rust、MSVC 或 Ollama；缺少环境时请按 [Tauri 前置要求](https://v2.tauri.app/start/prerequisites/) 安装。

### 本地数据

| 路径 | 内容 | 提交 Git |
| --- | --- | --- |
| `.cache/app-data/` | 开发版设置和下载记录 | 否 |
| `.cache/` | npm、临时文件、打包缓存、本机记录 | 否 |
| `.tools/` | 可选便携工具链 | 否 |
| `src-tauri/target/` | Rust 产物与安装包 | 否 |
| `src-tauri/gen/` | Tauri 生成的 schema | 否 |
| `package-lock.json`、`src-tauri/Cargo.lock` | 精确依赖版本 | 是 |

发布版默认使用 `%APPDATA%/com.localollama.desktop/`。应用标识 `com.localollama.desktop` 保留以兼容已有设置，不随展示名称改变。

需要独立客户端数据目录时，在启动前设置：

```powershell
$env:LOCAL_OLLAMA_DATA_DIR = Join-Path $PWD '.cache/my-app-data'
npm run desktop:dev
```

开发脚本保留已设置的值。设置和任务记录分别为 `settings.json`、`downloads.json`，不存储模型文件。Ollama 模型目录由服务端的 `OLLAMA_MODELS` 决定。

## 架构

```text
React 页面
  └─ use-app / use-translation
       └─ lib/commands.ts → Tauri invoke / Channel
            ├─ commands.rs → ollama.rs → 本机 Ollama HTTP API
            ├─ downloads.rs → 串行队列 / NDJSON 流 / 状态持久化
            ├─ library.rs → Ollama 官方网页解析
            ├─ settings.rs → 配置校验与 JSON 存储
            └─ tray.rs → 窗口隐藏、恢复、退出
```

Rust 负责网络、下载任务和持久化；React 负责界面和交互。浏览器预览没有桌面权限，不访问 Ollama。

### 前端

- `src/App.tsx`：菜单、切页、退出确认和下载弹窗。
- `src/pages/`：仪表盘、本地模型、模型库、运行中、下载任务、设置。
- `src/hooks/use-app.tsx`：连接、模型、下载状态和生命周期，操作后复查服务状态。
- `src/lib/commands.ts`：集中封装 Tauri 命令。
- `src/lib/en.json`、`i18n.ts`：以中文文案为键的英文词典，支持参数替换。
- `src/components/ui/`：shadcn/ui 组件源码。

页面采用黑白灰。主要文字 14px，辅助文字 12px，页面标题 20px，仪表盘数值 24px；区分常规和加粗。顶部“刷新 / 下载模型”操作组仅在本地模型页显示。最小窗口 960 × 640。

### 模型与连接

- 仅接受本机 HTTP 回环地址，允许更改端口，不接受路径、账号密码、查询参数或远程主机。
- 使用 Ollama 的版本、模型列表、运行列表、详情、加载/卸载、删除和拉取接口。
- 加载/卸载后查询运行列表，不能把“请求已发送”当作成功。
- 缺失值显示“—”，不伪造硬件使用率。模型文件大小合计不等于去重后的磁盘占用。
- 下载中的同名模型不可删除；已加载模型需先卸载再删除。
- 前台轮询逻辑见 `use-app.tsx`，页面不可见时不持续按前台频率请求。

### 下载队列

- 默认串行执行；相同实例和规范化模型名不能重复创建活动任务。
- 支持排队、中止、重试、清除已结束任务。
- 从 NDJSON 流解析进度，按 digest 记录层，显示当前层进度；最终成功响应才标为完成。
- 速度按当前层增量计算，切层重置。总量未知时使用不确定进度。
- 中止只关闭本客户端 HTTP 请求，其他客户端的请求可能继续。
- 重启后原活动任务标为已中断；重试使用新执行标识，丢弃旧事件。
- 有活动下载时禁止修改服务地址，客户端记录按服务地址隔离。

### 官方模型库

`library.rs` 请求 `https://ollama.com/` 的搜索、详情和标签页，不执行远端脚本。过滤云标签，下载仍通过本机 Ollama 拉取接口完成。

网页结构不是稳定 API；解析失败应显示错误和重试。修改解析器时维护内联 HTML 测试，可选网络测试单独运行，默认测试不依赖外部网站。

### 语言与托盘

支持 `zh-CN` / `en-US`，旧配置默认中文。保存语言后同步更新页面和原生托盘菜单。应用名称在两种语言下均为 `ollama ui`。

关闭或最小化隐藏窗口，任务继续；托盘恢复窗口。有活动下载时退出需要确认并保存状态。

### 图标

源图标为 `assets/brand/app.ico`，前端为 `src/assets/app-icon.png`，浏览器为 `public/favicon.ico`，Windows 资源在 `src-tauri/icons/`。

替换时同步更新这些文件；`build.rs` 监测 `icons` 目录，重新嵌入 EXE 图标。检查生成资源与最终 EXE，避免只更新页面 Logo。

## 验证边界

默认测试不需要真实 Ollama；Rust 下载测试使用本机随机端口模拟服务。两个可选测试依赖网络或本地捕获的 HTML，默认忽略，见 [验证记录](验证记录.md)。

CI 在 Windows 上检查格式、前端、Rust 和安装包。CI 不代替安装、托盘、系统缩放和真实模型联调，发布前仍需人工检查。
