# 验证记录

本页记录可复现的检查方法和范围，不包含本机路径、个人数据、旧程序备份或模型目录。

## 自动检查

| 检查 | 命令 | 范围 |
| --- | --- | --- |
| 类型 | `npm run typecheck` | TypeScript 项目 |
| 前端构建 | `npm run build` | 类型检查、Vite 生产资源 |
| 前端测试 | `npm test` | 格式化、名称/地址校验、任务事件、语言和日期 |
| Rust 格式 | `npm run desktop:fmt:check` | Rust 源码和 build.rs |
| Rust 检查 | `npm run desktop:check` | 原生编译 |
| Rust 测试 | `npm run desktop:test` | 配置兼容、输入校验、流解析、下载队列、HTML 解析 |
| Windows 打包 | `npm run desktop:build` | release EXE 和 NSIS 安装包 |

测试结果由执行输出和 GitHub Actions 记录确认。默认 Rust 测试不需要真实 Ollama；下载测试使用本机临时 HTTP 服务。

## 可选模型库检查

默认忽略两个测试：

- `official_library_live_requests`：需要访问 `ollama.com`，读取真实搜索和标签数据。
- `parses_captured_official_pages`：需要准备 `.cache/library-source/search.html` 与 `tags.html`，内容需匹配测试中 SmolLM2 的断言；捕获文件不随仓库提供，日常回归使用内联 HTML 用例。

在配置好 Rust 的终端中，可显式运行实时测试：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --locked official_library_live_requests -- --ignored --nocapture
```

此测试不是 CI 默认要求，官方页面变化或网络失败可能导致失败。
